Bracketed editor drafts (e.g. kindred's gossip, the three step-testimony drafts, the two decoy testimonies) are kept in each guest's `notes` field, not mixed into the copy fields.
- Added `src/lib/data.ts`, the build-time loader: parses every JSON file through its Zod schema and exposes `getGuest`, `getAllGuestSlugs`, `getTable`, `getAllTableSlugs`, `getAllTables`. A malformed field now fails at `npm run build` with a Zod error naming the exact field and allowed values — verified by deliberately corrupting `king.json`'s `eraBand` (see report) and reverting.
- Verified data integrity with a throwaway script (not committed): every guest link's `slug` resolves to a real guest or is explicitly `null`, and every table's `guests` array agrees with each listed guest's own `table` field. No mismatches found.
- Scope change: Madhura asked to pull table pages forward into this session ("a zoomed-in view of the reunion hall"), reversing the earlier BACKLOG deferral. See BACKLOG.md "From session 01, Gate 4" for the full note.
- Built `/word/[slug]/page.tsx`: name in era font (`eraFontClassName`), record text + source links, gossip in pencil hand, testimony, relative links (target word + label; a `null`-slug link like Germ's "cousin-german" renders as plain text, no href), and nav back to the guest's table (omitted for floaters, who have no single table) plus the hall. Phone layout stacks top to bottom; the 1440px layout switches to the two-column grid from the Desktop-WordA2 mockup (record left, gossip/testimony/relatives right), stripped of the mockup's SVG/crayon/place-card decoration per the explicit out-of-scope list.
- Built `/table/[slug]/page.tsx`: table name, route/event, one fixed setup line, each seated guest linking to their word page (name in era font) with one fixed pointer line, and a link back to the hall. No evidence column — still out of scope (see BACKLOG).
- Built the hall page (`src/app/page.tsx`), replacing the placeholder: all 5 tables grouped with their guests shown as dashed `[object · word]` placeholder links (the convention from CLAUDE.md/mockups, reused instead of the mockups' hand-drawn place cards), table names now link to their table page, plus a Floaters section for the 4 floater guests.

- Found and removed `export const dynamicParams = false` from both dynamic routes: the project's scaffolded `next.config.ts` has `cacheComponents: true` (Next 16's Cache Components), which rejects that route-segment export outright at build time. 404 behaviour for unknown slugs still works correctly without it — each page calls `notFound()` itself when `getGuest`/`getTable` returns undefined. Verified with `curl -sD -` against a local `next start` server: known slugs return `200`, `/word/nonexistent` and `/table/nonexistent` both return `404` with Next's not-found page.
- Verified no horizontal scroll at 360px and no overflow at 1440px on all four page types (word, floater word, table, hall) with a Playwright script comparing `scrollWidth` to `clientWidth` — all equal. Screenshots taken at both widths for visual review.
